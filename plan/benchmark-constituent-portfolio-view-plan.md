# 指数成分股持仓式展示计划

## 目标

- 指数详情页的成分股区域参照基金“公开持仓”展示方式，而不是使用需要横向滚动的宽表。
- 同时展示成分明细、权重较上一快照变化和行业配置。
- 保留指数特有的排名、交易所、快照覆盖范围、数据来源信息。

## 实施拆分

1. 数据展示逻辑：将当前与上一成分股快照按证券代码匹配，计算权重变化与新进状态；按行业汇总有效权重。
2. 页面结构：桌面端使用“成分明细 1.25 / 行业配置 0.75”双栏，移动端纵向堆叠；成分表采用基金持仓的紧凑四列布局。
3. 行业配置：复用基金持仓的环形图视觉语义；`top10` 快照明确标注为“前十大成分行业配置”，不冒充完整指数行业分布。
4. 快照切换：切换日期时同时更新成分明细、上一期变化、行业配置和来源说明。

## 验证

- 单元测试覆盖排序、上一快照权重变化、新进、行业聚合及缺失权重/行业。
- E2E 验证桌面双栏、行业图、快照切换和 390px 无横向溢出。
- 运行全量单元测试、TypeScript、ESLint、生产构建和发布检查。
- 提交并推送当前 `main`；部署前创建外部 PostgreSQL 备份，复用 `portfolio-journal_postgres_data`，部署后验证数据计数和私有访问。
