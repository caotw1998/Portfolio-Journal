# 牛熊区间自适应标注修复计划

## 目标

- 牛熊区间标注根据区间在图上的实际像素宽度等比例缩小，避免成立来视图中互相遮挡或显示不全。
- 添加基准后，每个有效区间同时展示主标年化、基准年化和年化超额。
- 极窄区间保留可点击入口，点击后在图下方显示完整区间和三项指标。

## 实施

1. 保留 ECharts 牛熊背景色，移除画布内固定字号文字。
2. 用可访问的 HTML 覆盖层按坐标轴实际像素位置绘制标签，并在图表完成渲染、容器缩放、时间范围或基准变化后重新计算。
3. 标签分三级适配：
   - 区间宽度 >= 96px：完整四行，字号随宽度从 9px 增至 11px。
   - 56px <= 区间宽度 < 96px：缩写四行，字号从 7px 增至 9px，并错层排列。
   - 区间宽度 < 56px：单行缩写、90 度旋转，字号从 6px 增至 7px。
4. 有基准时固定包含主标年化、基准年化、年化超额；无可比数据时显示 `--`，不伪造数值。
5. 点击标签显示完整牛熊区间名称、实际首尾交易日及三项完整指标。

## 验证

- 单元测试覆盖 40/56/95/96/140px 边界、等比例字号、无基准和有基准文案。
- TypeScript 类型检查及现有全量单元测试。
- Playwright 桌面 1440px 与移动 390px 验证成立来多区间、基准指标、无横向溢出、点击完整信息。
- 部署前备份数据库并复用现有 `portfolio-journal_postgres_data`，部署后核验健康状态及远程 SHA。
